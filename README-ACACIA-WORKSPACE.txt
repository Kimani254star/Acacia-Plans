ACACIA WORKSPACE
================

This is one installable application built from the supplied Acacia Books source so the two modules use the real Acacia Books implementations and data structures.

MODULE MAPPING
--------------
1. Acacia Plans = the Acacia Books Plans & Projects group: Plan Hub / Plan Management, Plan Progress, Plan Revenue, and related plan tracking screens.
2. Acacia Projects = the Acacia Books Budgets submodule, relabelled in the workspace as “Acacia Projects · Budget Management”. It retains the original budget management forms, planned monthly values, actuals, comparison/variance views, and related budget actions from the supplied Books source.

The former standalone Acacia Projects task-management module is not used as the Projects module in this corrected build.

INSTALL / DEPLOY
----------------
1. Upload the contents of this folder to the root of an HTTPS website (for example, a Vercel project).
2. Open the deployed index.html in Chrome or Edge.
3. Sign in, then use the sidebar: “Acacia Plans” for the Plan module and “Acacia Projects · Budget Management” for the Budget submodule.
4. Choose “Install app” in the browser to install on desktop or supported mobile devices. On iPhone, open the site in Safari and use Share > Add to Home Screen.

A secure HTTPS origin is required for service-worker installation. Cloud sync and any remote services require internet access.
